# 内心 OS 文案规范

内心 OS 是 XR/Beam Pro 上的短文本旁白，与机器人实际口播分离。它不是思维链，也不解释模型如何得出结论。

## 输出约束

- 默认 8–28 个中文字符，单条只表达一个状态或下一步。
- 说明“我正在做什么/注意到什么/准备做什么”，不冒充未经确认的观察。
- 不重复完整口播；机器人说事实，内心 OS 补充情绪或行动意图。
- 过期事件在 `expiresAt` 后不再显示；`stop` 或新高优先级事件可以覆盖。

## 例子

| 场景 | 口播 | 内心 OS |
|---|---|---|
| 工作陪伴 | 我在这里陪你。 | 安静陪你一会儿。 |
| 日程提醒 | 提醒你：团队会议。 | 提醒已经到时间了。 |
| 自主农场 | 我去自己的小田看看。 | 你专心工作，我把自己的小田照顾好。 |
| 人脸问候 | 我看到你了。 | 确认到面对面互动。 |

运行时固定文案在 `content/runtime/inner-os-lines.json`；Agent 生成的自由文本必须经过长度、敏感信息和事实边界检查，失败时回退到固定文案。
