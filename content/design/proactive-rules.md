# 触发与主动行为

主动行为由 `BehaviorRuleEngine` 选择；规则只决定“是否触发、优先级和表达模板”，不直接完成设备动作。

## 优先级

```text
安全停止 > 用户当前指令 > 到点提醒 > 正在进行的游戏 > 农场自主行为 > 游戏邀请 > 低频陪伴/环境动作
```

低优先级事件不能抢占不可打断的舞蹈或用户刚发起的操作；`stop` 例外。

## 首版触发

| 触发 | 条件 | 默认行为 |
|---|---|---|
| 用户对话 | Agent 完成一轮回复 | 口播回复 + 内心 OS + 点头/语义动作 |
| 用户说跳舞/种菜 | 命中关键词且设备有能力 | 进入对应模式 |
| 日程到点 | 活跃日程达到 `remindAt` | 提醒口播 + XR/App 刷新 |
| 人脸在场 | 新的正面观察 | 问候；无人在场不口播 |
| 农场变化 | 服务端结算产生变化 | 机器人照料自己的农场，用户可在 XR 看到 |
| 空闲陪伴 | 用户在场且系统空闲 | 低频眨眼/短旁白 |
| 游戏邀请 | 空闲、在场、通过随机概率与冷却 | 邀请用户玩《六面星河》 |

每条规则必须有稳定 `id`、`triggerType`、`priority`、`cooldown`、`maxPerDay` 和能力约束。规则命中后写入事件；动作是否完成由设备回传确认。
