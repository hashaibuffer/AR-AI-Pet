# 比赛材料

## 模块用途

保存比赛 PPT、Demo 脚本、视频分镜、Demo 视频和现场交付材料。这里描述实际演示内容，不定义产品或技术能力。

## 主责人

C。A、B确认材料中涉及各自模块的能力已经实际运行。

## 当前状态

目录入口已建立；正式比赛材料待 C 按开发计划提交。

## 交付要求

- Demo 脚本写明演示顺序、所需设备和降级方式。
- PPT、分镜和视频只展示已经实现或明确标记为待验证的能力，不得把计划能力写成已完成。
- 每项材料注明用途、版本和是否可直接用于比赛。
- PPT、视频及其他大型二进制文件按仓库 `.gitattributes` 使用 Git LFS；首次提交前执行 `git lfs install`。

## 验证方式

C检查叙事、画面和体验是否成立；A、B按 [`docs/07-测试与Demo验收.md`](../docs/07-测试与Demo验收.md) 确认涉及的客户端、服务和设备能力。最终材料必须完成实际打开、播放和完整 Demo 流程检查。

## 已知问题

当前没有已验收的正式比赛材料。未验证能力不得写入成片或作为现场承诺。
