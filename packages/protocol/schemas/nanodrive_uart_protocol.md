# NanoDrive UART 协议

版本 v0.9 · 115200 8N1 · 每条消息以 `\n` 结束

## 当前连接边界

当前没有 5V→3.3V 电平转换，只启用 StackChan→NanoDrive 单向控制：

| 接线 | 当前状态 |
|---|---|
| StackChan TX（黄）→ NanoDrive RX | 使用 |
| GND（黑）↔ GND | 使用 |
| NanoDrive TX（绿）→ StackChan RX | 不接 |
| 5V（红） | 不接，两端分别供电 |

因此 StackChan 只能确认 UART 写入成功，不能确认 NanoDrive 已收到或返回状态。协议保留返回消息，供 NanoDrive USB 单机测试和以后增加电平转换后使用。

## 指令

| 指令 | 参数 | 作用 |
|---|---|---|
| `PING` | 无 | 返回固件版本 |
| `EN` | `0` / `1` | 禁用或使能；`EN:1` 同时解除急停 |
| `FW` / `BW` | `0..255` | 前进 / 后退 |
| `TL` / `TR` | `0..255` | 原地左转 / 右转 |
| `VL` | `left,right`，各 `-255..255` | 左右轮差速 |
| `ST` | 无 | 立即停止并进入急停状态 |
| `GS` | 无 | 查询编码器、电池和安全状态 |
| `TO` | `0..10000` ms | 设置运动超时，`0` 为关闭 |
| `RS` | 无 | 清零编码器 |
| `DI` | 无 | 查询左右编码器中断是否触发过 |

## 返回

| 返回 | 含义 |
|---|---|
| `OK:PONG:v0.9` | 连接和版本正常 |
| `OK:EN:n` / `OK:ST` / `OK:TO:n` / `OK:RS:0` | 指令已执行 |
| `ST:L123,R456,V7680,E0,M1` | 左右编码器、电池 mV、急停、运动中 |
| `DI:L1,R1` | 左右编码器中断均触发过 |
| `ERR:DISABLED` | 电机未使能 |
| `ERR:ESTOP` | 急停后尚未重新 `EN:1` |
| `ERR:TIMEOUT` | 运动指令超过看门狗时间，已停车 |
| `ERR:FORMAT` / `ERR:UNKNOWN` | 格式或指令错误 |

## 安全约束

- 上电默认禁用且停止。
- 当前看门狗为 2000 ms，只在运动期间计时。
- `ST` 后必须再次发送 `EN:1` 才能运动。
- StackChan 对外动作默认限制速度为 `0..180`，NanoDrive 固件仍接受 `0..255`。
- 编码器当前在 A 相 `CHANGE` 中断计数，实际里程换算需实机标定，不在本协议中预设倍频、轮径或减速比。
