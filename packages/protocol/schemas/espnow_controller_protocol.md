# ESP-NOW 遥控协议 v1

遥控器与 StackChan 使用固定 24 字节帧。所有多字节整数均为小端序；末字节为 CRC8（多项式 `0x07`）。

| 偏移 | 长度 | 字段 |
| ---: | ---: | --- |
| 0 | 2 | 魔数 `A7 50` |
| 2 | 1 | 协议版本 `1` |
| 3 | 1 | 消息类型：输入、状态、模式指令 |
| 4 | 1 | `HEAD / BASE / GAME_YAHTZEE / GAME_FARM` |
| 5 | 1 | 标志：停止、在线 |
| 6 | 4 | 单调递增序号 |
| 10 | 4 | 标准化摇杆 X/Y，范围 `-1000..1000` |
| 14 | 4 | 原 StackChan 头部 yaw/pitch |
| 18 | 4 | 按键保持状态、按下沿事件 |
| 22 | 1 | Agent 模式指令 |
| 23 | 1 | CRC8 |

安全规则：只有 `BASE` 输入允许生成底座速度；其他模式强制停止。离开 `BASE` 的首帧带停止标志；StackChan 超过 300 ms 未收到新输入也必须停止底座。遥控器超过 1 秒未收到 StackChan 状态回执显示离线。重复或倒序输入由接收端丢弃。
