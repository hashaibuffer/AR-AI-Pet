### Agent 与工具链决定

- QwenPaw 已废弃，历史运行材料仅作归档。
- AgentScope 不是当前运行时，也不再安排二选一验证。
- 项目自有 Agent Runtime 作为当前文字主 Agent；Xiaozhi/StackChan 保留为设备语音与实体能力。
- Xiaozhi 云端不作为当前项目外部 MCP 的挂载入口；语音协议网关后续单独实现。**Demo 语音通道为 StackChan 侧 Xiaozhi 语音会话**（已按 `docs/10` 验收），语音协议网关后续实现指与本地 Agent Runtime 的协议级集成，不影响 Demo 用 Xiaozhi 语音作为展示通道（见 `docs/08` 技术决策）。
- 以 Agent 调用真实工具并交付结果作为闭环验收，不为理论可行的依赖单独增加无业务意义的 Smoke。

### Agent 体验编排

本轮已采用项目内 `PersonaLoader`、`BehaviorRuleEngine`、`ExperienceOrchestrator` 和 `ProactiveScheduler`，以 `AGENT_EXPERIENCE_SMOKE_OK` 验证 Mock Unity/Robot 与 PostgreSQL 事件落库。StackChan—NanoDrive 的独立 BLE 实体闭环已通过；真实 Unity、项目 Agent 对该实体链路的调用和真实 Mem0 仍分别验收，不合并为完整端到端通过。
