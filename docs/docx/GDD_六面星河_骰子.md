# 第一部分：路演概述

### 1. 一句话定位

戴上 Xray 眼镜，桌上那台真实的小机器人坐到你对面，桌面中央亮起一圈全息光阵——五颗发光的骰子在里面翻滚碰撞。一款忠实经典 Yahtzee 规则核心、以全息高科技视觉呈现的桌面骰子策略对战，单局 7~10 分钟，碎片时间友好。赢取的金币进入家园统一钱包，反哺农田与家园。

### 2. 目标用户

| 维度   | 描述                                             |
| ---- | ---------------------------------------------- |
| 核心人群 | 喜欢轻策略、数字组合乐趣的休闲玩家；已拥有/愿意购入 Xray 眼镜与桌面机器人的科技爱好者 |
| 次要人群 | 碎片时间寻求「一局即满足」的 AR 体验者                          |
| 导流入口 | 已在家园农田中积累、想换换口味的玩家（酒馆在农场 Lv2 即新手教程后解锁）         |

### 3. 核心卖点与差异化

| 卖点          | 说明                                        |
| ----------- | ----------------------------------------- |
| **实体对手**    | 坐在你对面的不是一段代码，而是桌上那台真会动的小机器人，它会对你的每一手骰做出反应 |
| **全息骰子**    | 发光骰体在桌面光阵里翻滚，无实体丢失风险，AR 沉浸感拉满             |
| **AR 虚拟分身** | 实体机器人之上叠加全息孪生分身，表情张力与夸张表演远超纯实体            |
| 全息科技视觉      | 数据流计分表、粒子填分、ALL IN 数据风暴，区别于传统桌游美术         |
| 两重策略决策      | 每回合「保留哪几颗、冲哪个牌型」的策略选择                     |
| 人机博弈        | 两档 AI，普通档会算概率、会冲牌型                        |
| 双通道交互       | 指向 + 捏合 + 语音，无任何屏幕按钮，符合眼镜第一人称范式           |
| 家园经济互通      | 对局金币进入家园统一钱包，可买皮肤或反哺农场种子                  |

### 4. 灵感参考

经典 **Yahtzee（快艇骰子）** 规则基底；《忘川风华录》「更金换物」玩法灵感。

### 5. 商业模式

**待定（demo 阶段不做变现）**。
### 6. 核心循环

```
进入家园酒馆 → 选难度 → 全息对局(投骰/保留/重投/计分) → 结算(金币+段位分) → 回家园(花金币) → 再来一局
```

# 第二部分：详细设计

## 一、游戏概述

「六面星河」是家园酒馆内的骰子策略对战。玩家与**实体桌面机器人**轮流投掷 5 颗**全息骰子**，通过「保留+重投」凑高分组合填入 11 格计分表，11 回合后总分高者获胜。机器人坐于桌对面，是 AI 对手的具象化身——它会对你的掷骰做出反应（屏脸+头动+灯带+分身）、会因胜负而庆祝或认输；眼镜再为其叠加一个全息分身，把情绪表现推向夸张。机器人自身不掷骰，掷骰始终由玩家发起。

> **与经典 Yahtzee 的差异**：去掉「葫芦(FULL HOUSE)」和「大顺(STREAK 5)」两个牌型，计分表从 13 格精简为 11 格，单局节奏更紧凑。

## 二、核心规则

### 2.1 基本配置

| 项目   | 说明                             |
| ---- | ------------------------------ |
| 玩家人数 | 2（1 玩家 + 1 实体机器人 AI）           |
| 道具   | 5 颗**全息** 6 面骰子（点数 1~6，发光呈现）   |
| 回合数  | 双方各 **11 回合**，交替进行（共 22 个操作回合） |
| 投掷机会 | 每回合 1 次初投 + 2 次重投 = **3 次投掷**  |
| 计分   | **11 格**计分表，每格整局只能填一次          |
| 胜利   | 11 回合后总分高者获胜                   |

### 2.2 回合流程

```
初投（5 颗全丢）→ 选保留（0~4 颗）→ 第一次重投 → 调整保留 → 第二次重投 → 选格计分 → 换对手
```

> - 每格只能填一次；即使得 0 分也必须选一个空格填入。
> - 也可以在初投或第一次重投后直接选格计分，放弃后续重投。

### 2.3 先手与整体流程

- **先手规则**：玩家默认先手，设置中可切换。
- 流程：玩家 → AI → 玩家 → AI ……双方各填满 11 格后比对总分。
- **支持中途存档**：整局状态可序列化，随时暂停、跨会话恢复（眼镜主机端本地 JSON）。

## 三、计分表

### 3.1 上半区（6 格，基础分）

每格只计算指定点数骰子之和：

| 格 | 名称 | 计分方式 | 理论最高（5颗全中） |
|---|---|---|---|
| 1 | ONE | 所有 1 点之和 | 5 |
| 2 | DOUBLE | 所有 2 点之和 | 10 |
| 3 | TRIPLE | 所有 3 点之和 | 15 |
| 4 | QUAD | 所有 4 点之和 | 20 |
| 5 | PENTA | 所有 5 点之和 | 25 |
| 6 | HEX | 所有 6 点之和 | 30 |

**上半区奖励**：6 格合计 ≥ 63 分 → 额外 **+35 分**。

> 63 = 每格平均 3 颗对应骰子（3×1 + 3×2 + 3×3 + 3×4 + 3×5 + 3×6 = 63）。

### 3.2 下半区（5 格，特殊牌型）

| # | 名称 | 条件 | 计分 | 理论最高 |
|---|---|---|---|---|
| 7 | **3-MATCH** | ≥3 颗同点 | 5 颗总和 | 30 |
| 8 | **4-MATCH** | ≥4 颗同点 | 5 颗总和 | 30 |
| 9 | **STREAK 4** | ≥4 颗连续 | 固定 **30** | 30 |
| 10 | **ALL IN!** | 5 颗全同 | 固定 **50** | 50 |
| 11 | **FREE ROLL** | 任意组合 | 5 颗总和 | 30 |

> **已移除牌型**（相对原 Yahtzee 13 格）：
> - ~~FULL HOUSE（葫芦：3同+2同，固定25分）~~ — 移除
> - ~~STREAK 5（大顺：5颗连续，固定40分）~~ — 移除

### 3.3 牌型判定与可填边界

**有效组合定义：**

| 牌型 | 有效组合 |
|---|---|
| STREAK 4 | 1-2-3-4 / 2-3-4-5 / 3-4-5-6（需 5 颗骰子中至少 4 颗构成连续） |
| ALL IN | 5 颗完全相同（如 6-6-6-6-6） |

**可填边界规则（高阶可填低阶格）：**

- **4-MATCH** 自然满足 3-MATCH 条件 → 可填 3-MATCH 格。
- **ALL IN（5同）** 自然满足 4-MATCH、3-MATCH、FREE ROLL 条件 → 可填这些格。
- 即使手牌满足某牌型条件，玩家也可选择填入 **FREE ROLL**（拿 5 颗总和）或任意空格（含 0 分格）。
- **不设「万能牌」规则**：ALL IN 不可填入 STREAK 4（5 颗全同不构成连续）。

> 设计意图：简化策略空间，11 格均有明确独立判定，降低新手认知负担。

### 3.4 理论最高分（已修正）

> **原文档 9.2 称 450 分**，其中上半区「6 格 ×(5×6)=180」数学上不可能（5 颗骰子无法同时拥有 5 个 6 点和 5 个 1 点）。已修正。

修正后理论最高分（理想投掷、每回合独立计算）：

**上半区：**

| 格 | 理想投掷 | 得分 |
|---|---|---|
| ONE | 1-1-1-1-1 | 5 |
| DOUBLE | 2-2-2-2-2 | 10 |
| TRIPLE | 3-3-3-3-3 | 15 |
| QUAD | 4-4-4-4-4 | 20 |
| PENTA | 5-5-5-5-5 | 25 |
| HEX | 6-6-6-6-6 | 30 |
| **小计** | | **105** |
| **奖励（≥63）** | | **+35** |
| **上半区合计** | | **140** |

**下半区：**

| 格 | 理想投掷 | 得分 |
|---|---|---|
| 3-MATCH | 6-6-6-6-6 | 30 |
| 4-MATCH | 6-6-6-6-6 | 30 |
| STREAK 4 | 3-4-5-6-x | 30 |
| ALL IN | 6-6-6-6-6 | 50 |
| FREE ROLL | 6-6-6-6-6 | 30 |
| **下半区合计** | | **170** |

**理论最高总分 = 140 + 170 = 310 分**

## 四、对战规则

### 4.1 对局流程

```
游戏开始 → 回合1(玩家: 投骰+保留+重投+计分) → 机器人(投骰+保留+重投+计分)
→ 回合2(玩家) → 机器人 → ... → 回合11(玩家) → 机器人 → 终局结算
```

### 4.2 终局结算

```
总分 = 上半区6格合计 + (≥63 ? +35 : 0) + 下半区5格合计

玩家 > 机器人 → 胜利
玩家 = 机器人 → 平局（记1次平局，不加赛）
玩家 < 机器人 → 失败
```

### 4.3 中途存档

| 项目 | 说明 |
|---|---|
| 存档时机 | 任意时刻可暂停存档（指向+捏合呼出暂停，或语音「暂停」） |
| 存档内容 | 骰子当前值、保留状态、剩余重投次数、双方计分表、当前回合/轮次、当前操作方 |
| 恢复方式 | 家园酒馆入口「继续对局」项，读取后从暂停点继续 |
| 存档槽数 | 多存档槽，可同时进行多局（眼镜主机端本地 JSON） |

## 五、AI 设计

### 5.1 难度档位

demo 阶段实装 **两档**，困难档后置。

| 档位 | 保留策略 | 填表策略 | 失误率 | 状态 |
|---|---|---|---|---|
| **轻松** | 随机保留 2~3 颗 | 顺序从上往下填 | ~50%（近似随机） | demo |
| **普通** | 优先冲高分牌型（按概率） | 合理分配，留 FREE ROLL 到最后 | 15% | demo |
| ~~困难~~ | ~~expectimax 期望值搜索~~ | ~~最优填格~~ | ~~<5%~~ | 后置 |

**默认难度**：新手引导后首战 = **轻松**。

### 5.2 轻松档行为

- **保留**：每次投掷后随机保留 2~3 颗骰子（不做策略判断）。
- **填表**：从上到下顺序填入第一个可填的空格（不选最优格）。
- 效果：近似随机玩家，给新手「能赢」的正反馈。

### 5.3 普通档参数表

| 参数             | 值              | 说明                      |
| -------------- | -------------- | ----------------------- |
| 上半区优先级权重       | 0.4            | 优先填上半区对应点数格             |
| 保留最小同点数        | 2              | 至少保留 2 颗同点骰子            |
| FREE ROLL 保留回合 | 最后 2~3 回合      | 前期不急着填 FREE ROLL        |
| 赌小顺阈值          | 已有 4 连且概率 >85% | 决定是否冲 STREAK 4          |
| 失误概率           | 15%            | 有 15% 概率做次优选择（非最优填格/保留） |
| 冲 ALL IN 条件    | 已有 4 同且剩余重投 ≥1 | 决定是否赌第 5 颗              |

> **与 13 格版的差异**：移除了「赌大顺阈值」（STREAK 5 已删除）；FREE ROLL 保留窗口从「最后 3 回合」调整为「最后 2~3 回合」（适配 11 回合）。

## 六、AR 交互（Xray 眼镜 + 全息骰子）

> 本章为架构改造核心。从手机 AR 的「点击屏幕按钮」全面迁移为「指向 + 捏合 + 语音」双通道，无任何屏幕按钮。骰子为全息呈现，投掷区为锚定在真实桌面的全息光阵。眼动凝视不在当前设计范围（可行性未定），以手部追踪当光标指向替代。

### 6.1 全息骰子与投掷区

| 项目 | 说明 |
|---|---|
| **投掷区（光阵）** | 锚定在真实桌面平面中央的一块全息圆环 + 网格（直径约 15cm），作为骰子活动边界 |
| **骰体** | 5 颗全息发光骰子；点数以内部光纹/数字呈现，清晰可辨 |
| **出手表现** | 投掷时，光粒在**全息光阵中心**凝聚成形 → 在光阵内碰撞、滚动、静止（物理模拟） |
| **保留态** | 被保留的骰子浮起、泛金光、移出碰撞区，视觉上「锁定」 |
| **无实体骰子** | 骰子完全虚拟，规避实体骰子掉落/丢失/识别难题；机器人仅做反应（屏脸/头动/灯带/分身），不碰真实物体（安全） |

> 体验目标：玩家透过眼镜看到 5 颗发光的骰子从光阵里「飞出来」在桌上翻滚——机器人则用屏脸/头动/灯带/分身对结果做出反应，保留「AI 在陪你玩」的临场感，又无实体风险。

### 6.3 双通道交互（指向 + 捏合 + 语音）

核心组合：**指向选中 + 捏合确认**（手部追踪当光标，指向目标即高亮）；语音作为完整替代通道（满足《桌屿》8.4「手势与语音必须互为完整替代」红线）。

| 动作        | 指向 + 捏合                   | 语音指令（完整替代）              |
| --------- | ------------------------- | ----------------------- |
| 投掷 / 初投   | 指向光阵 + 抛掷手势（捏合甩腕）         | 「投掷」「掷骰」                |
| 保留 / 取消保留 | 指向某颗骰子 + 捏合 切换            | 「保留 1、3、5」「取消保留」        |
| 重投        | 指向 AR「重投」按钮 + 捏合          | 「重投」                    |
| 选格计分      | 指向计分表某空格 + 捏合 确认（二次确认防误触） | 「填 ALL IN」「填 FREE ROLL」 |
| 暂停 / 图鉴   | 指向角落图标 + 捏合               | 「暂停」「打开图鉴」              |
| 返回家园      | 手掌下压（全局手势）/ 语音「回家园」       | —                       |

> **防误触设计**：选格计分采用「指向+捏合 → 高亮预览 → 再次捏合确认」两步；语音填格同样在确认前在计分表上高亮预览 1 秒。
> **计分自由顺序**：11 格任意回合可填任意空格，**无上半区 / 下半区先后约束**；上半区 +35 奖励只看终局上半区 6 格合计是否 ≥63。

### 6.4 AR 容错（三层，与家园共用底座）

强制 AR 无降级前提下，复用《桌屿》第七章 7.2 三层容错：

| 层级              | 场景          | 处理                                            |
| --------------- | ----------- | --------------------------------------------- |
| **第 1 层：首进强引导** | 首次检测失败      | 分步引导（调光线/清理桌面/更换位置），未成功不进入对局                  |
| **第 2 层：锚定后容错** | 短暂丢追踪（<3s）  | 使用最后有效锚点继续渲染，画面轻微冻结但不中断；机器人减速待命               |
| **第 3 层：重锚机制**  | 长时间丢追踪（>3s） | 弹出「重新对齐桌面」提示，指向桌面 2s 或语音「重新对齐」即可快速重锚，对局状态完整保留 |

> 这是强制 AR 最大的流失风险点，三层容错缺一不可。对局中途若机器人跑出视野（>3s），语音提示「小屿跑到你看不见的地方了，转头看看」，不中断对局逻辑。（重锚不依赖眼动凝视，用指向桌面 2s 或语音「重新对齐」即可。）

## 七、美术

### 7.1 整体风格

**全息高科技简约风**。与农田「治愈田园」形成反差，进入酒馆后通过家园风格桥接（外观暖色小屋 + 透出冷蓝霓虹）平滑转入全息空间。

### 7.2 各元素设计

| 元素            | 设计                                         |
| ------------- | ------------------------------------------ |
| **全息骰子**      | 半透明发光体，落定后点数以内部光纹显现；保留态浮起泛金光               |
| **光阵（投掷区）**   | 深蓝底 + 青蓝光网格 + 边缘数据流，锚定桌面                   |
| **计分表**       | 悬浮全息面板，半透明质感，粒子从骰子汇入计分格                    |
| **填分特效**      | 粒子从骰子汇入计分格，光纹扫描写入                          |
| **高分特效(≥30)** | 数据爆裂动画，粒子四散后重组                             |

## 十四、实体机器人表现

### 14.1 角色定位

实体桌面机器人是家园系统中玩家的陪伴角色（与农场中的机器人是**同一角色**）。在酒馆里，它坐于桌对面，**作为 AI 对手的具象化身**出场；眼镜为其叠加 AR 虚拟分身，把情绪表现推向夸张。

| 项目    | 说明                                                                               |
| ----- | -------------------------------------------------------------------------------- |
| 身份    | 玩家的家园陪伴机器人（跨场景同一角色）                                                              |
| 实体层   | 真实物理机身（圆润低模暖色），圆形 LCD 面屏（实体显示基础表情）；**无机械臂**，头部可点头/摇头/前倾/转头，底盘带滚轮可小幅移动/转向，机身灯带可变色 |
| AR 层  | 全息虚拟分身，锚定在实体位姿之上，表情张力与夸张幅度远超纯实体（可跳跃/旋转/变形）                                       |
| 位置    | 真实桌面对侧（玩家正前方 ~30~50cm 处），面向玩家                                                    |
| 与农场联动 | 机器人外观/等级在农场养成，酒馆 AR 分身中同步显示                                                      |

### 14.1.1 实体 × AR 分身 分层

| 层           | 内容                                                | 失败兜底                       |
| ----------- | ------------------------------------------------- | -------------------------- |
| **实体屏脸**    | ~12 种基础眼睛表情（睁眼/眨眼/开心/失落/震惊/思考/生气/困倦…），由自带 LCD 呈现  | 摘下眼镜也能看到，是「本体人格」           |
| **实体微动**    | 头部俯仰/偏航（点头/摇头/前倾/转头）、滚轮底盘小幅移动/转向、灯带情绪色            | 机器人离线 → AR 虚拟替身接管（《桌屿》6.5） |
| **AR 虚拟分身** | 夸张表情、情绪符号（`!?` / `zzz` / `♥` / 汗滴）、腮红、变形、跳跃/旋转/光晕 | 眼镜未佩戴 → 仅实体层成立             |

**分工示例——机器人在酒馆输了一局：**

| 层 | 表现 |
|---|---|
| 实体 | 面屏切换 `T_T`，头部低下 15°，底盘后缩，灯带转蓝，扬声器播低沉音效 |
| AR 分身 | 头顶飘落灰色小雨云，肩膀冒「唉…」文字气泡，身体轮廓短暂灰化、缩成一团 |

> **实体保证下限，AR 拉高上限**：摘下眼镜，你看到一个低着头蓝灯的小机器人；戴上眼镜，它头上还下着雨、缩成一团。

### 14.2 对掷骰的反应（机器人不掷骰，掷骰由玩家发起）

**掷骰始终由玩家发起**（指向光阵 + 抛掷手势，或语音「掷」）；全息骰子从光阵飞出弹跳静止后，机器人用屏脸 + 头动 + 灯带 + AR 分身对结果做出反应。机器人偶尔会主动说「让我先开始吧~」抢先请战，但玩家保有否决权（仍可自己先掷）。

| 阶段       | 实体                | AR 分身           | 耗时    |
| -------- | ----------------- | --------------- | ----- |
| **期待**   | 面屏亮起专注眼、头部前倾、灯带脉冲 | 分身搓手虚影 / 环绕粒子   | ~0.3s |
| **落定观察** | 头部随骰动微转、面屏盯向结果    | 分身身体前倾，头顶冒计算符号  | ~0.5s |
| **结果反应** | 见 14.4（头动/底盘/灯带）  | 见 14.4（夸张表情/符号） | 即时    |

> **关键体验**：玩家自己把骰子「甩」进光阵，桌对面那个小机器人立刻用屏脸、点头、灯带和头顶的分身对你的牌做出反应，临场感来自「它在陪你玩、会对你起反应」。

**难度差异化反应风格：**

| 难度 | 反应风格 | 实体可见细节 | 分身夸张细节 |
|---|---|---|---|
| **轻松** | 随意、笨拙、滞后 | 偶尔看错（头转向错误骰再转回来）；灯带反应慢半拍 | 分身做出「哎呀」表情、冒问号、反应延迟 ~0.3s |
| **普通** | 专注、迅速、精准 | 头随骰精准转动；灯带随结果即时变色 | 分身自信挑眉、反应迅速 ~0.1s |

### 14.3 闲置动画

玩家思考/操作时，实体机器人与 AR 分身双重呈现，让桌面「活」起来（仅用屏脸/头动/底盘/灯带，无手臂动作）：

| 动画 | 实体表现 | AR 分身表现 | 触发频率 |
|---|---|---|---|
| 东张西望 | 头部左右转动，面屏眼睛扫视 | 分身头随动，视线方向飘出小箭头 | 随机 ~15s |
| 点头打盹 | 头部缓缓上下点动，灯带呼吸变缓 | 头顶冒「zzz」全息粒子漂浮 | 玩家停留 >15s |
| 底盘转圈 | 滚轮底盘小幅原地转圈，灯带流光 | 拖影光圈随转 | 随机 ~20s |
| 好奇前倾 | 头部 + 底盘前倾，面屏睁大眼 | 头顶冒问号 | 随机 ~25s |

> 闲置动画实体层仅产生轻微机械音（头部/底盘伺服，机器人扬声器），分身层为纯视觉；不干扰玩家思考。

### 14.4 实时反应表情（三层联动，无臂）

机器人面屏为自带 LCD，AR 分身叠加夸张表情。实体层仅用屏脸 + 头部/底盘/灯带（无手臂），夸张肢体动作交由 AR 分身承载。以下为各类触发条件及三层反应：

#### A. 玩家回合——对玩家掷骰结果的反应

| 触发事件 | 实体面屏 | 实体微动 | AR 分身表情 |
|---|---|---|---|
| 玩家掷出 ALL IN | `⊙⊙` 闪 | 后仰、底盘后缩，灯带亮 | 头顶冒「!?」，身体后弹（虚拟） |
| 玩家掷出高分(≥30) | `>_<` | 摇头、灯带闪 | 冒「可恶」气泡，跺脚（虚拟） |
| 玩家掷出 STREAK 4 | `O_O` | 身体前倾，头探向骰子 | 探身盯骰子，冒惊叹号 |
| 玩家掷出低分(≤10) | `·_·` | 头微抖，灯带缓暗 | 偷笑符号，肩膀抖动放大（虚拟） |
| 玩家填 0 分格 | `^▽^` | 头部左右摇 | 「不行的哦」文字气泡 |
| 玩家触发上半区奖励(+35) | `=_=` | 灯带不情愿闪 | 不情愿特效，冒青筋 |

#### B. AI 回合——对自己掷骰结果的反应

| 触发事件 | 实体面屏 | 实体微动 | AR 分身表情 |
|---|---|---|---|
| AI 掷出 ALL IN | `★▽★` | 底盘小跳（滚轮）、抬头，灯带金 | 头顶「WIN」符号爆开，光环（虚拟跳跃） |
| AI 掷出高分(≥30) | `^▽^` | 头部轻点，灯带亮 | 冒「yes!」气泡 |
| AI 掷出低分(≤10) | `T_T` | 低头，灯带转蓝 | 头顶乌云，缩团（虚拟） |
| AI 填 0 分格 | `Σ(°△°)` | 头歪向一侧 | 冒「??」气泡，转圈圈（虚拟） |
| AI 触发上半区奖励 | `‾▽‾` | 抬头挺胸，灯带金 | 胸口奖章发光，冒星星（虚拟） |

#### C. AI 思考中（决定保留哪几颗）

| 状态 | 实体面屏 | 实体微动 | AR 分身 |
|---|---|---|---|
| 计算中 | `◐◑` 轮转 | 头部侧倾（托腮状） | 头顶飘数字/公式全息符号 |
| 犹豫（普通档触发失误时） | `?_?` | 头左右看骰子 | 冒问号，拿不定主意 ~1s |

### 14.5 终局反应

终局结算时，实体机器人与 AR 分身同步表演，与胜负结果绑定（实体仅用屏脸/头动/底盘/灯带，跳跃/旋转等夸张肢体交给分身）：

| 结果 | 实体反应 | AR 分身反应 |
|---|---|---|
| **玩家胜利** | 愣住(`⊙_⊙`)→点大头(`^▽^`)→微低头；灯带暖光 | 头顶「GG」粒子，鞠躬放大特效，鼓掌光环（虚拟） |
| **玩家失败** | 抬头(`★▽★`)→底盘小幅转一圈；灯带蓝闪 | 头顶「WIN!」粒子，转圈拖影（虚拟），偶尔伸舌头鬼脸 |
| **平局** | 头部耸肩、与玩家对视一秒，低头看桌面 | 头顶「= =」气泡，无奈摊手（虚拟） |

> 终局表演在结算 AR 面板展示时同步播放，不阻塞玩家「再来一局」/「回家园」。玩家透过眼镜看到的是：**真实桌上一个在庆祝/低头的小机器人 + 它头上夸张的分身表演 + 浮在桌面的结算面板**。

### 14.7 技术实现要点

| 项目 | 说明 |
|---|---|
| **实体位姿** | 机器人顶部 AprilTag + BLE 里程计，卡尔曼滤波融合得到高频稳定位姿（误差 <1cm，见《桌屿》6.2） |
| **分身锚定** | AR 虚拟分身 mesh 锚定到机器人位姿之上（带轻微偏移，环绕实体），随实体移动/转动实时跟随 |
| **时序同步** | 玩家掷骰飞出与机器人反应（头/底盘/灯带/分身）同时发生，误差 <100ms（见《桌屿》6.3）；AR 特效跟随实体微动，而非反之 |
| **分身动作驱动** | 实体动作经 retargeting 映射到分身骨骼；分身额外动作（跳跃/旋转）由游戏状态触发，不与实体冲突 |
| **面屏表情库** | 预制 ~12 种实体 LCD 表情 + 分身全息表情/符号库，按事件查表触发 |
| **优先级** | 终局反应 > 实时反应 > 闲置动画；高优先级打断低优先级（三层一致） |
| **性能** | 分身 mesh 低面数（~2000 三角面），LOD 分档；全息骰子/光阵粒子受全局粒子上限约束（同屏 ≤800，见《桌屿》12.2） |
| **抖动处理** | 分身位置跟随实体位姿平滑插值（lerp），过滤实体微抖 |
| **跨场景同步** | 机器人外观（颜色/装饰/等级标记）从农场存档读取，酒馆分身实例化时应用 `[提案]` |
| **离线降级** | 机器人未开机/离线时，AR 生成**虚拟机器人替身**（含分身），玩法完整可用（见《桌屿》6.5） |

### 14.8 难度与机器人性格映射

| 难度 | 性格关键词 | 表现差异 |
|---|---|---|
| **轻松** | 呆萌、随意、不靠谱 | 反应笨拙（偶尔看错骰、灯带慢半拍）；闲置动画更频繁更夸张；反应延迟略大(~0.3s)；失败时反应更戏剧化 |
| **普通** | 专注、自信、有策略感 | 出骰利落；闲置动画克制；反应迅速(~0.1s)；胜利时更骄傲 |
