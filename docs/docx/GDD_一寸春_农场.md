# 第一部分：路演概述

### 1. 一句话定位

**《一寸春》是一款在你真实书桌上生长的四季农场。**

戴上眼镜，桌上出现一块巴掌大的田；桌上那台真实的小机器人会走过去，弯下腰，替你浇一垄水。春种胡萝卜，夏收玉米，秋摘南瓜，冬看向日葵，一年 56 个回合，一寸桌面，一整个春天。

### 2. 目标用户与使用场景

| 维度       | 描述                                                        |
| -------- | --------------------------------------------------------- |
| 核心人群     | 喜欢种田/放置类轻经营，追求「无压力、有进展」的休闲玩家                              |
| 次要人群     | 桌面机器人用户，想跟机器人有进一步交互                                       |
| **典型场景** | 工作间隙 5 分钟：戴上眼镜 → 收一茬熟了的菜 → 让机器人浇水 → 播下新种 → 过一天 → 摘下眼镜继续工作 |
| 使用频次预期   | 每天 1~3 次，每次 3~8 分钟                                        |

### 3. 核心卖点

| 卖点                 | 说明                                                                  |
| ------------------ | ------------------------------------------------------------------- |
| **机器人会干活，拥有自己的生活** | 你说「浇水」或手势指引，桌上那台机器人真的转身、走过去，AR 水流从它手里洒出来；平时它能自己耕种自己的田地，成为一个居家娱乐的好伙伴 |
| **一寸桌面，四季轮转**      | 春夏秋冬各 14 回合，每季有专属作物与视觉变化，桌角的这块田会有换季的视觉表现                            |
| **零惩罚经营**          | 换季不会绝收，已种的继续长，不给上班族添压力                                              |
| **协作而非放置**         | 机器人不是自动挂机器，它有自己的小田、会发委托、会跟你分成，是**合作者**不是工具                          |
| **语音指挥**           | 手上忙着？直接说「XX，全部浇水」                                                   |
| **跨玩法反哺**          | 在酒馆赢的钱能买种子，田里赚的钱能买骰子皮肤                                              |

### 4. 竞品与差异

| 竞品      | 借鉴          | 我们的差异                         |
| ------- | ----------- | ----------------------------- |
| 星露谷物语   | 四季机制、作物成长节奏 | 我们是桌面尺度 + 单次 5 分钟 + 无体力/无压力   |
| 开心农场类   | 轻量循环、收获快感   | 我们有实体机器人协作与 AR 呈现             |
| 动物森友会   | 家园建设与陪伴感    | 我们的「居民」是真实存在于桌上的硬件            |
| 放置类种田手游 | 挂机收益        | 我们强调「在场感」：你戴上眼镜时世界才活起来，机器人一直在 |

### 5. 商业模式

**demo 阶段不做变现**，商业模式待验证后确定。文档内金币为游戏内货币。

### 6. 核心循环

```
   ┌──────────────────────────────────────────────┐
   │                                              │
   ↓                                              │
 查看田块状态 → 收获成熟作物 → 卖出得金币          │
                    ↓                             │
              买种子 / 播种                        │
                    ↓                             │
        浇水（自己浇 or 指挥机器人浇）              │
                    ↓                             │
           处理机器人委托 / 互助                    │
                    ↓                             │
              「过一天」推进回合 ──────────────────┘
                    ↓
        （累计收入达标）农场升级 → 解锁新作物/新地
                    ↓
        （每 14 回合）季节切换 → 新的可种作物
```

# 第二部分：详细设计

## 一、玩法概述

《一寸春》是家园「农田」区的回合制种植经营玩法。玩家在 AR 田块上耕地、播种、浇水、收获、卖出，赚取金币扩大农场规模、解锁新作物；同时与实体桌面机器人协作——它有自己的小田，会接受玩家指挥，也会主动发布委托。

| 项目   | 定义                      |
| ---- | ----------------------- |
| 玩法类型 | 回合制轻经营                  |
| 胜负   | **无胜负**，以成长与解锁为驱动       |
| 单次时长 | 3~8 分钟（推进 1~5 回合）       |
| 完整周期 | 一年 = 56 回合（4 季 × 14 回合） |
| 失败条件 | 无失败                     |
| 核心张力 | 有限的土地/回合 vs 想种更多更贵的作物   |

> **设计红线：无压力原则。** 不设体力,不设倒计时惩罚。这是面向「工作间隙玩 5 分钟」用户的根本约束。

---

## 二、回合制与时间系统

### 2.1 回合定义

| 项目       | 规则                          |
| -------- | --------------------------- |
| 1 回合     | = 游戏内 1 天                   |
| 一季       | 14回合                        |
| 单回合内操作次数 | **不限**（耕、种、浇、收、卖可任意顺序、任意多次） |
| 回合不可回退   | 推进后不可撤销，推进前有确认提示（可关闭）       |


### 2.2 「过一天」的结算顺序

点击「过一天」后按固定顺序结算，全过程有 AR 演出（约 2.5s）：

```
1. 已浇水的作物 → 生长值 +1
2. 达到成熟回合的作物 → 状态转为「可收获」
3. 机器人自主行为结算（它的田播种/浇水/收获）
4. 委托进度更新 / 新委托生成
5. 季节回合数 +1 → 若达 14，触发季节切换
6. 农场等级检查 → 达标则升级并解锁
7. AR 演出：天空色变化（昼夜过渡）+ 作物生长动画 + 机器人伸懒腰
8. 结算面板：本回合变化摘要（可关闭）
```

### 2.3 时间视觉表现

| 元素 | 表现 |
|---|---|
| 天色 | 每回合推进时，AR 环境光做一次「黄昏 → 夜 → 清晨」的快速过渡（2.5s） |
| 季节色调 | 春嫩绿 / 夏浓绿金 / 秋橙黄 / 冬冷白，田块底色与作物色调随季变化 |
| 日期显示 | HUD 左上角：`春 · 第 7 天`（第 1 年第 7 回合） |
| 年度 | 满 56 回合进入第 2 年，HUD 显示 `第2年 · 春 · 第1天` |

## 三、土地与农场等级

### 3.1 农场等级与土地规模

| 农场等级 | 解锁条件（累计收入） | 玩家田规模 | 可用格数 | 新解锁作物 |
|---|---|---|---|---|
| **Lv.1** | 初始 | 2 × 2 | 4 | 胡萝卜、生菜 |
| **Lv.2** | 累计收入 300 金 | 3 × 3 | 9 | 玉米 |
| **Lv.3** | 累计收入 1,200 金 | 4 × 4 | 16 | 草莓 |
| **Lv.4** | 累计收入 3,000 金 | 5 × 5 | 25 | 南瓜 |
| **Lv.5** | 累计收入 6,000 金 | 6 × 6 | 36 | 向日葵 |

> **统一解锁原则**：作物与土地**全部**按农场等级解锁，不使用「收获次数」等第二套条件（原设计中两套并存的矛盾已消除）。

**「累计收入」定义**：整局游戏中通过卖出作物、委托奖励、收获里程碑奖励获得的金币总和（**不含**从酒馆/池塘转入的金币）。

> 为什么排除跨玩法收入：防止玩家靠刷骰子快速升级农场，跳过农田自身的成长节奏。

### 3.2 田块尺寸与 AR 呈现

| 项目 | 规格 |
|---|---|
| 单格尺寸 | 真实 3cm × 3cm |
| Lv.1 农田占地 | 6cm × 6cm |
| Lv.5 农田占地 | 18cm × 18cm |
| 田块间距 | 0.5cm（含田埂） |
| 扩建演出 | 升级时新格子从桌面「翻土升起」，机器人在旁鼓掌（~3s） |

> **尺寸设计依据**：3cm 格子在 40cm 观看距离下视角约 4.3°，足够手指精确点选，也足够机器人（底盘 9cm）在田埂外侧走位而不压田。

### 3.3 田块状态机

```
    ┌──────────┐   耕地    ┌──────────┐   播种   ┌──────────┐
    │  荒地     │ ────────→ │  空地     │ ───────→ │  已播种   │
    │ (Barren) │           │ (Tilled) │          │ (Seeded) │
    └──────────┘           └──────────┘          └────┬─────┘
                                 ↑                    │ 浇水 + 过天
                                 │                    ↓
                                 │              ┌──────────┐
                                 │              │  生长中   │
                                 │              │(Growing) │
                                 │              └────┬─────┘
                                 │                   │ 生长值 = 成熟回合
                                 │                   ↓
                                 │              ┌──────────┐
                                 └──────────────┤  可收获   │
                                     收获        │ (Ripe)   │
                                                └──────────┘
```

| 状态           | AR 表现                    | 可执行操作 |
| ------------ | ------------------------ | ----- |
| 荒地           | 灰褐色硬土，有小石子               | 耕地    |
| 空地           | 深褐色松土，有垄沟                | 播种    |
| 已播种          | 土上有小凸起                   | 浇水    |
| 生长中          | 作物模型分 3 阶段（幼苗/中株/成株）     | 浇水    |
| 可收获          | 作物成熟形态 + 头顶金色光点 + 轻微上下浮动 | 收获    |
| **缺水**（附加标记） | 土色变浅，作物叶片微垂              | 浇水    |

## 四、作物系统

### 4.1 作物总表

| 作物 | 种子价 | 售价 | 单次利润 | 成熟回合 | 利润/回合 | 解锁等级 | 可播种季节 |
|---|---|---|---|---|---|---|---|
| 🥕 **胡萝卜** | 10 | 25 | 15 | 3 | 5.0 | Lv.1 | 春 |
| 🥬 **生菜** | 15 | 35 | 20 | 4 | 5.0 | Lv.1 | 春 / 秋 |
| 🌽 **玉米** | 30 | 70 | 40 | 6 | 6.7 | Lv.2 | 夏 |
| 🍓 **草莓** | 50 | 120 | 70 | 8 | 8.8 | Lv.3 | 夏 / 冬 |
| 🎃 **南瓜** | 80 | 200 | 120 | 12 | 10.0 | Lv.4 | 秋 |
| 🌻 **向日葵** | 100 | 260 | 160 | 15 | 10.7 | Lv.5 | 冬 |

**设计校验：**
- 利润/回合从 5.0 单调递增到 10.7，高级作物始终更优，成长感明确
- 但高级作物**占用格子时间更长**（向日葵 15 回合 vs 胡萝卜 3 回合），在格子紧张的早期，短周期作物反而灵活——形成真实的策略取舍
- 所有作物成熟回合 ≤ 14（一季长度），**仅向日葵 15 回合需跨 1 回合到下一季**（已确认允许跨季继续生长）

### 4.2 作物生长阶段

| 生长进度 | 阶段 | AR 模型 |
|---|---|---|
| 0% ~ 33% | 幼苗 | 两片小叶 |
| 34% ~ 66% | 中株 | 茎叶伸展 |
| 67% ~ 99% | 成株 | 接近成熟但无果实 |
| 100% | 可收获 | 完整果实 + 光点特效 |

> 每种作物 4 个模型档位，共 24 个模型。低模，单个 ≤ 300 三角面。

### 4.3 浇水机制

| 规则 | 说明 |
|---|---|
| 生长条件 | 一块田在「过一天」时**当回合已浇过水**，生长值才 +1 |
| 未浇水 | 生长值不变（**不枯萎、不倒退**），田块显示「缺水」标记 |
| 重复浇水 | 同回合重复浇水无额外效果，但也不惩罚 |
| 浇水方式 | ①玩家手势浇 ②语音指挥机器人浇 ③机器人自动浇（Lv2+ 能力） |
| 浇水范围 | 玩家：单格；机器人：随等级 1 格 → 3 格 → 全田 |

### 4.4 收获与售出

| 项目   | 规则                                 |
| ---- | ---------------------------------- |
| 收获   | 点击可收获田块 / 语音「收获」/ 机器人 Lv3 自动收获     |
| 收获产出 | 1 格 = 1 个作物，进入仓库                   |
| 售出   | 在仓库面板或机器人屋「一键卖出」，立即得金币             |
| 收获后  | 田块回到「空地」状态（保留耕地，无需重新耕）             |
| 批量   | 支持「收获全部」（手势/语音），逐格播放收获动画（间隔 0.15s） |

### 4.5 收获里程碑奖励

| 里程碑 | 奖励 | 说明 |
|---|---|---|
| 首次收获某作物 | +50 金 + 图鉴解锁 | 每种作物一次性 |
| 累计收获 10 次 | 齿轮 ×2 | 机器人升级材料 |
| 累计收获 30 次 | 齿轮 ×5 | |
| 累计收获 60 次 | 齿轮 ×8 | |
| 累计收获 100 次 | 齿轮 ×10 + 装饰「金锄头」 | |
| 连续 5 回合有收获 | +100 金 | 鼓励持续经营 |

> **齿轮是机器人升级的主要材料来源**（钓鱼产出的「芯片」为辅），确保不玩钓鱼也能把机器人养满级。

## 五、种植操作流程

### 5.1 完整操作链

```
 ① 耕地    注视荒地格 + 捏合 → 机器人/玩家翻土 → 变空地
 ② 买种    打开种子面板 → 选作物 → 确认购买（扣金币）→ 入仓库
 ③ 播种    从仓库拖拽种子到空地格 / 注视空地 + 选种子 → 播下
 ④ 浇水    手势「洒水」/ 语音「浇水」→ 机器人执行
 ⑤ 过天    手势/语音「过一天」→ 结算演出
 ⑥ 收获    注视成熟格 + 捏合 / 语音「收获」
 ⑦ 售出    仓库面板「卖出」→ 得金币
```

### 5.2 单格操作的 AR 表现

| 操作 | 玩家自己做 | 指挥机器人做 |
|---|---|---|
| **耕地** | 手掌向下做「压土」手势，AR 泥土翻起粒子 | 机器人走到格边，双臂前伸下压，AR 泥土翻起 |
| **播种** | 捏合种子拖到格上松手，AR 种子落下 | 机器人走到格边，手臂前伸「撒」，AR 种子落下 |
| **浇水** | 手掌摊平做「洒」的动作，AR 水滴从掌心落下 | 机器人手臂前伸下压，AR 水流从末端喷出 |
| **收获** | 捏合成熟作物向上「拔」，作物飞入仓库 | 机器人前伸夹取，作物飞入仓库 |

> **关键体验**：玩家自己动手时，AR 特效跟随**自己的手**；指挥机器人时，特效跟随**桌上真实机器人的机械臂**。两种都有物理临场感。

### 5.3 批量操作

| 操作 | 触发 | 效果 |
|---|---|---|
| 全部浇水 | 语音「全部浇水」/ 手势横扫全田 | 机器人依次走过所有需浇水格（Lv1）或整片一次浇完（Lv3） |
| 全部收获 | 语音「收获所有」 | 逐格收获，0.15s 间隔 |
| 全部售出 | 仓库「一键卖出」 | 弹确认，显示总额 |

> **等待感处理**：机器人 Lv1 逐格浇水较慢（每格约 3s）。玩家可随时手势中断，改为自己浇；或直接跳过等待，机器人在后台继续（不阻塞其他操作）。

## 六、季节系统

### 6.1 基本参数

| 参数 | 值 |
|---|---|
| 季节数 | 4（春 → 夏 → 秋 → 冬 → 春…） |
| 每季长度 | **14 回合** |
| 一年 | 56 回合 |
| 开局 | 第 1 年 · 春 · 第 1 天 |
| 天气模拟 | **无**（预留接口，post-MVP 可加） |

### 6.2 季节的唯一作用：限制「可新播种」的作物

| 规则          | 说明                                  |
| ----------- | ----------------------------------- |
| **限制播种**    | 只能播种当季允许的作物；非当季作物在种子面板中置灰（可购买，不可播种） |
| **不影响已种作物** | 已经种下的作物**继续正常生长**，跨季不枯萎、不暂停、不减速     |
| **不影响收获**   | 任何季节都能收获成熟作物                        |
| **不影响售价**   | 售价全年恒定（不做季节价格波动，避免增加计算负担）           |


### 6.3 作物 × 季节映射

| 季节       | 可播种作物  | 设计意图                      |
| -------- | ------ | ------------------------- |
| 🌱 **春** | 胡萝卜、生菜 | 新手起步季，两种低门槛作物             |
| ☀️ **夏** | 玉米、草莓  | 中期主力，利润跃升                 |

**兜底设计**：生菜（Lv1）横跨春秋，草莓（Lv3）横跨夏冬——保证**任何等级的玩家在任何季节都至少有一种可种作物**，不出现「这一季我什么都种不了」的空窗。

## 七、机器人协作系统

> 机器人是**实体硬件**（详见《桌屿 Deskle》第五章）。本章定义它在农场中的行为与玩法价值。它不是自动挂机工具，而是**有自己的田、会提要求、会分成的合作者**。

### 7.1 定位：中度协作

| 它是什么           | 它不是什么                  |
| -------------- | ---------------------- |
| 能被指挥干活的帮手      | ❌ 不是全自动托管（不会替你玩完整个游戏）  |
| 有自己的小田、自己种菜的邻居 | ❌ 不是独立经济体（没有自己的金库）     |
| 会发布委托、给你奖励的任务源 | ❌ 不是随机事件生成器（委托与玩家状态相关） |
| 可养成升级的长线目标     | ❌ 不是战斗单位               |

### 7.2 四大协作模块总览

```
        ┌──────────────────────────────────┐
        │        机器人协作系统              │
        └──┬──────┬──────┬──────┬─────────┘
           ↓      ↓      ↓      ↓
      ①自主种植 ②任务委托 ③双向互助 ④养成升级
      (它的小田) (给玩家活) (互相帮忙) (3级成长)
           │      │      │      │
           └──────┴──────┴──────┘
                  ↓
         资源流：玩家供种 → 机器人种 → 7/3 分成
                 收获里程碑 → 齿轮 → 机器人升级
```

### 7.3 ① 自主种植（机器人的小田）

| 项目 | 规则 |
|---|---|
| 田规模 | 初始 **2 × 2**；农场 Lv.3 → **3 × 3**；农场 Lv.5 → **4 × 4** |
| 位置 | 机器人屋旁，与玩家田分开 |
| 种子来源 | **玩家供种**——玩家设置「可用种子白名单」，机器人只从白名单中随机选 |
| 白名单 | 玩家在机器人屋面板勾选允许它使用的作物；未勾选的（如稀有作物）它绝不会动 |
| 种子消耗 | 消耗玩家仓库中的实际种子；仓库无对应种子时它会空等并提示「小屿没种子了」 |
| 自主行为 | 每回合结算时：有空地→随机播种；有已种未浇→浇水；有成熟→收获 |
| 收成分配 | **玩家 70% / 机器人 30%** |
| 机器人那 30% 去哪 | 不是消失——转化为**委托奖励池**与**升级材料**，最终仍回馈给玩家 |

**7/3 分成的实际计算：**

```
机器人田收获 1 个南瓜（售价 200 金）
  → 玩家直接获得 140 金（70%）
  → 60 金（30%）进入「机器人存钱罐」
  → 存钱罐每满 300 金 → 机器人发布一个「高额委托」，奖励 200 金 + 齿轮 ×3
```

> **设计意图**：分成不是玩家的损失，而是**延迟返还 + 转化为互动**。玩家感受到的是「机器人拿走一点点，然后用它给我发红包」。

### 7.4 ② 任务委托

机器人主动向玩家发布任务，完成得奖励。

| 委托类型            | 内容示例                    | 奖励                  |
| --------------- | ----------------------- | ------------------- |
| **种植交付**        | 「我想吃 3 个玉米，能给我吗？」       | 金币（约作物售价 130%）或稀有种子 |
| **代管协助**        | 「帮我给我的田浇 4 次水好不好？」      | 金币 + 齿轮 ×1          |
| **高额委托**（存钱罐触发） | 「我攒了点钱，帮我种 5 个南瓜，我全买了！」 | 200 金 + 齿轮 ×3       |

| 参数 | 规格 |
|---|---|
| 同时可接数 | 机器人 Lv.1 → 1 个；Lv.2 → 2 个；Lv.3 → 3 个 |
| 生成频率 | 每 3 回合检查一次，有空位则生成 |
| 有效期 | **无限期**（不做限时，契合无压力原则） |
| 拒绝 | 可拒绝，机器人短暂失落（表情 `._.`），2 回合后重新生成 |
| 委托板位置 | 机器人屋 AR 面板；有新委托时机器人主动靠近玩家提示 |
| 难度适配 | 委托内容根据玩家当前等级/可种作物生成，不会要求玩家种不出来的东西 |

**委托发布的 AR + 实体表现：**

```
机器人（实体）转身面向玩家 → 小跑靠近 → 抬头
面屏表情：`^o^`
AR 叠加：头顶弹出感叹号气泡
语音：「主人，我想吃三个玉米！」
AR 面板：委托卡片浮现在机器人上方，含[接受][拒绝]按钮
```

### 7.5 ③ 双向互助

| 方向 | 内容 | 效果 |
|---|---|---|
| **玩家 → 机器人** | 帮它的田浇水、收获 | 增加「好感度」；好感度影响委托奖励系数（+0~20%） |
| **机器人 → 玩家** | 帮玩家浇水、收获、耕地、播种 | 玩家指挥即执行；Lv.3 后可自动执行 |

**好感度系统 `[提案]`：**

| 好感度 | 获取 | 效果 |
|---|---|---|
| 0 ~ 100 | 帮它浇水 +2 / 帮它收获 +3 / 完成委托 +5 / 夸奖（语音）+1（每日上限 5） | 每 20 点，委托奖励 +5%（上限 +20%） |
| 衰减 | 连续 5 回合无互动 -5 | 表现为机器人情绪低落（灯带转蓝、动作变少） |

### 7.6 ④ 养成升级

| 等级 | 升级材料 | 浇水范围 | 委托上限 | 分成比例 | 新能力 |
|---|---|---|---|---|---|
| **Lv.1** | 初始 | 1 格 | 1 个 | 70/30 | 基础协作（耕/种/浇/收，需指挥） |
| **Lv.2** | 齿轮 ×10 | 3 格（一次一行） | 2 个 | 75/25 | 移动速度 +50%；自主种植效率提升 |
| **Lv.3** | 齿轮 ×25 + 芯片 ×3 | 整片田 | 3 个 | 80/20 | **自动收获**：过天时自动收走成熟作物入仓 |

| 材料 | 来源 | 备注 |
|---|---|---|
| **齿轮** | 收获里程碑（主）、代管委托 | 不玩钓鱼也能满级 |
| **芯片** | 钓鱼产出（主）、高额委托（辅） | Lv.3 需 3 个；**若钓鱼未上线，改由高额委托必掉** |

> **升级不花金币**——避免与作物投资争夺资源，让养成成为纯粹的「陪伴积累」回报。

**升级演出：** 机器人回到机器人屋 → 基站亮起 → AR 光柱笼罩 → 实体机器人原地转一圈、灯带彩虹流光 → 面屏 `★▽★` → AR 显示新能力卡片。

### 7.7 语音指令（专用于机器人）

> 输入体系详见《桌屿 Deskle》第八章。农场内语音**专门用于指挥机器人**，农田本身的精细操作用手势。

| 指令 | 别名 | 行为 |
|---|---|---|
| **「浇水」** | 「浇一下」「给它浇水」 | 浇注视中的格；无注视目标时浇最需要的格 |
| **「收获」** | 「收了」「摘下来」 | 收注视中的成熟格；无目标时收最近一个 |
| **「播种」** | 「种上」「种这个」 | 在注视空地播种当前选中的种子 |
| **「接受委托」** | 「答应你」「好啊」 | 接受当前展示的委托 |
| 批量扩展 | 「全部浇水」「收获所有」 | 批量执行 |
| 呼唤 | 「小屿过来」 | 机器人移动到玩家面前 |

| 参数 | 规格 |
|---|---|
| 识别延迟 | <500ms（本地关键词） |
| 反馈 | 识别成功：机器人面屏闪一下 + 「嗯！」；失败：面屏 `?_?` + 「没听清」 |
| 静音模式 | 可全局关闭，所有指令有手势等价路径 |

### 7.8 机器人在农场中的情绪表现

> 机器人表情 = **实体面屏（基础）+ AR 叠加（增强）**，详见《桌屿 Deskle》6.4。

| 触发 | 实体表现 | AR 叠加 |
|---|---|---|
| 玩家收获大丰收（一次 ≥5 格） | 面屏 `★▽★`，双臂举高，灯带彩虹 | 头顶撒花粒子 |
| 玩家帮它浇水 | 面屏 `^▽^`，转向玩家点头 | 头顶飘爱心 |
| 完成委托交付 | 面屏 `^o^`，原地小跳（前后晃动） | 「谢谢！」文字气泡 |
| 它自己的田丰收 | 面屏 `^▽^`，手臂挥动 | 作物上方金色光点 |
| 它没种子了 | 面屏 `._.`，低头，灯带黄闪 | 头顶空袋子图标 |
| 玩家连续多回合不互动 | 面屏 `-_-`，动作变缓，灯带转蓝 | 头顶飘小雨云 |
| 季节切换 | 转圈一周，面屏 `⊙▽⊙` | AR 换上季节配饰 |
| 升到新等级 | 转圈，灯带流光 | 光柱 + 等级徽章升级动画 |

## 八、经济系统

### 8.1 经济结构

```
   收入                                支出
   ├─ 卖作物（主）                      ├─ 买种子（主）
   ├─ 首次收获奖励 +50/种               ├─ 买装饰（Lv2 后）
   ├─ 连续收获奖励 +100                 └─ 家园/机器人皮肤
   ├─ 委托奖励
   ├─ 机器人分成（70%）
   └─ 跨玩法转入（酒馆/池塘）
                    ↓
            统一钱包（家园层管理）
```

### 8.2 起始配置

| 项目 | 值 |
|---|---|
| 起始金币 | **50 金** |
| 起始种子 | 胡萝卜 ×2（引导用） |
| 起始土地 | 2 × 2（4 格，已耕好 1 格作为教学） |
| 起始机器人 | Lv.1，2×2 小田（空） |

> **50 金的依据**：够买 5 颗胡萝卜种子（10 金/颗），刚好铺满 4 格田还剩 1 颗备用。既不宽裕也不窘迫。

### 8.3 阶段经济曲线

| 阶段 | 回合 | 农场等级 | 金币区间 | 关键行为 |
|---|---|---|---|---|
| **新手期** | 1 ~ 14（春 1） | Lv.1 | 50 → ~300 | 4 格田种胡萝卜/生菜，完成新手任务，冲 Lv.2 |
| **成长期** | 15 ~ 42（夏 1、秋 1） | Lv.2 → Lv.3 | 300 → ~1,500 | 9 格田，玉米主力，机器人加入协作 |
| **稳定期** | 43 ~ 84（冬 1 ~ 夏 2） | Lv.3 → Lv.4 | 1,500 → ~3,500 | 16 格田，草莓，机器人 Lv.2，委托常态化 |
| **富农期** | 85 ~ 140 | Lv.4 → Lv.5 | 3,500 → ~8,000 | 25→36 格田，南瓜/向日葵，机器人 Lv.3 |
| **后期** | 140+ | Lv.5 满 | 8,000+ | 装饰收集、纪录挑战、跨玩法消费 |

**新手期收益推演（验证 300 金目标可达）：**

```
起始 50 金 + 胡萝卜种子 ×2

回合 1：耕 4 格，买 2 颗胡萝卜种子（-20，余 30），播 4 格（含起始 2 颗）
回合 1~3：浇水，过天 ×3
回合 4：收 4 个胡萝卜 → 卖 100 金（余 130）+ 首次收获奖励 50（余 180）
        再买 4 颗胡萝卜（-40，余 140），播种
回合 5~7：浇水过天
回合 8：收 4 个 → +100（余 240）
        买 4 颗生菜（-60，余 180），播种
回合 9~12：浇水过天（生菜 4 回合）
回合 13：收 4 个生菜 → +140（余 320）+ 首次收获生菜 50（余 370）
        ✅ 累计收入已达 340 → 农场升 Lv.2
```

> 结论：**在春季 14 回合内自然达成 Lv.2**，节奏合适。到达 Lv.2 恰好在第一次季节切换前后，酒馆与池塘同时解锁——形成一个强烈的正反馈时刻。

### 8.4 种子购买

| 项目 | 规则 |
|---|---|
| 购买入口 | 机器人屋「种子面板」/ 语音「买种子」 |
| 库存 | 无限量供应 |
| 非当季 | 可购买、可囤积，但不可播种（按钮置灰并提示「小麦四季都能种，玉米要等夏天」） |
| 未解锁 | 不可购买，显示解锁条件 |
| 批量 | 支持一次买多颗（滑块选数量） |
| 退货 | 不支持（避免套利） |

### 8.5 平衡关注点

| 关注点 | 分析 | 对策 |
|---|---|---|
| 机器人分成加速经济 | 4~16 格额外产出，相当于玩家田规模的 +50%~44% | 已计入曲线；若实测超速，下调分成至 60/40 或缩小机器人田 |
| 长周期作物性价比 | 向日葵 15 回合利润 160，同期可种 5 轮胡萝卜（利润 75）——向日葵明显更优 | 正确：高级作物应更优，但它占格 15 回合缺乏灵活性，且需 Lv.5 |
| 后期金币过剩 | Lv.5 后无处可花 | 靠装饰系统、机器人皮肤、跨玩法（骰子皮肤 80~800 金）吸收 |
| 跨玩法刷金 | 玩家在酒馆刷金买高级种子跳过成长 | ①农场等级只算农场自身收入 ②骰子收益效率刻意低于农田 |

## 九、AR 眼镜交互

> AR 基础能力（锚定/容错/光照/遮挡）详见《桌屿 Deskle》第七章，本章只写农场特有部分。

### 9.1 农田的 AR 空间布局

| 项目 | 规格 |
|---|---|
| 农田位置 | 家园布局中的左中区，距玩家 25~40cm |
| 观看姿态 | 自然低头俯视，无需弯腰 |
| 田块高度 | 田面略高于桌面 0.3cm（有厚度感，像一块真的地） |
| 作物最大高度 | 向日葵 5cm（最高），不遮挡后方机器人屋 |
| 交互距离 | 手可直接伸到田上方做手势（近场直接交互），也可远程注视+捏合 |

### 9.2 农场专属手势

| 手势 | 操作 | 说明 |
|---|---|---|
| 注视 + 捏合 | 选中田块 | 通用 |
| 手掌向下压 | 耕地 | 在目标格上方做压土动作 |
| 手掌摊平轻晃 | 浇水 | 掌心朝下，AR 水滴从掌心落下 |
| 捏合上提 | 收获 | 把作物「拔」起来 |
| 捏合拖拽 | 播种 | 从种子面板拖种子到格上 |
| 横扫全田 | 批量选择 | 配合语音确认执行 |
| 双手下压 | 「过一天」 | 有仪式感的推进动作 `[提案]` |

### 9.3 视觉反馈规范

| 事件 | 反馈 |
|---|---|
| 注视田块 | 田块边框亮起（暖黄描边），上方浮现状态标签 |
| 可交互提示 | 可收获格持续微浮动 + 金色光点 |
| 缺水提示 | 缺水格上方浮现半透明水滴图标 |
| 操作成功 | 对应粒子特效 + 音效 + 机器人反应 |
| 操作失败 | 田块短暂红闪 + 提示文字（如「这一季不能种玉米」） |
| 手势识别中 | 手部轮廓高亮，识别到手势后图标确认 |

### 9.4 舒适度

| 项目 | 处理 |
|---|---|
| 低头疲劳 | 农田可整体「抬起」到 15° 倾斜面（设置项），减少低头角度 |
| 长时间抬手 | 所有手势操作都有语音替代；批量操作减少重复手势 |
| 单次时长 | 15 分钟后提示休息（家园层统一） |

### 15.3 回合结算的实现要点

| 要点 | 说明 |
|---|---|
| 单一结算入口 | 所有「过一天」逻辑集中在 `TurnManager.AdvanceTurn()`，避免状态散落 |
| 结算原子性 | 结算过程中禁止玩家输入；异常时回滚到结算前快照 |
| 演出与逻辑分离 | 逻辑瞬时完成，演出异步播放；玩家可跳过演出不影响结果 |
| 机器人行为异步 | 机器人的物理动作不阻塞结算；结算立即完成，机器人慢慢去执行 |

### 15.4 机器人指令接口（农场相关）

| 指令 | 参数 | 返回 |
|---|---|---|
| `MoveTo(x, z, yaw)` | 家园坐标 | 到位/失败（超时/受阻） |
| `PerformAction(type)` | till / seed / water / harvest | 完成/失败 |
| `SetExpression(id)` | 表情 ID | ack |
| `SetLED(color, pattern)` | 颜色 + 模式 | ack |
| `Speak(clipId)` | 语音片段 ID | ack |
| `GoHome()` | — | 到桩/失败 |
| `ReportPose()` | — | (x, z, yaw, battery) @20Hz |

**失败处理：**

| 失败类型 | 处理 |
|---|---|
| 路径受阻（有杯子） | AR 播放机器人挠头动画，提示「小屿过不去，帮它挪一下？」，操作转为玩家手动 |
| 到位超时（>10s） | 取消该操作，机器人返回待命位 |
| 电量不足 | 自动回桩，AR 替身接管后续操作 |
| BLE 断连 | 立即停止移动，AR 显示离线标记，替身接管 |

### 15.5 性能要点

| 项目 | 措施 |
|---|---|
| 36 格田同屏 | 作物模型 GPU Instancing；远处格子降 LOD |
| 生长动画 | 用材质插值 + 缩放替代骨骼动画 |
| 粒子 | 对象池复用；同屏粒子上限 800（家园层统一预算） |
| 季节切换 | 材质色调用全局 Shader 参数统一控制，避免逐材质切换 |

## 十七、风险与对策

| 风险 | 等级 | 说明 | 对策 |
|---|---|---|---|
| **机器人动作等待感** | 🔴 高 | Lv.1 机器人逐格浇水，9 格要等 27 秒，玩家会烦 | ①AR 预告填补等待 ②玩家可随时接手自己浇 ③Lv.2 升级明显提速（做成升级的核心爽点）④批量操作后台异步执行，不阻塞 |
| **空间对齐误差导致穿帮** | 🔴 高 | 机器人手臂位置与 AR 田块错位 >1cm 时明显违和 | ①田块放大到 3cm 容纳误差 ②浇水特效从机器人**实际手臂位置**发出而非预设点 ③M0 阶段专项攻关 |
| **无压力设计导致缺乏动力** | 🟡 中 | 没有惩罚 = 没有紧迫感 = 可能不想上线 | 动力来自正向：解锁、升级、机器人陪伴与提醒、纪录、跨玩法 |
| **回合推进太快导致内容消耗过速** | 🟡 中 | 玩家连点「过一天」快速刷完 56 回合 | ①作物需浇水才生长，纯点过天无收益 ②每回合结算有 2.5s 演出（可跳过但有节奏感）③内容深度靠机器人养成与委托延展 |

| **语音在办公场景不可用** | 🟡 中 | 用户不方便出声 | 全部功能有手势等价路径；静音模式 |
| **实体机器人不可用** | 🟡 中 | 没买机器人/机器人坏了 | AR 虚拟替身接管，玩法完整 |
| **长期内容不足** | 🟡 中 | 玩过一年（56 回合）后无新内容 | post-MVP：图鉴、稀有变种、机器人故事线、季更活动 |

### A.5 AR 收线小游戏

```
1. 手势「抛竿」→ AR 浮标落入池塘
2. 等待（3~8s），机器人在旁边陪着看（实体转头看浮标）
3. 咬钩：浮标下沉 + 机器人突然站直 + 音效「咚！」
4. 收线：AR 显示张力条，玩家需保持手部高度让指针落在安全区
   - 手抬太高 → 线张力过大 → 断线
   - 手放太低 → 鱼跑掉
   - 持续 3~8s（随难度）
5. 成功 → 鱼跃出水面 + 机器人欢呼；失败 → 机器人做「哎呀」动作
```

| 参数 | 说明 |
|---|---|
| 安全区宽度 | 随鱼稀有度递减（★=40% / ★★★★=15%） |
| 加固鱼线 | 安全区 +30% |
| 失败惩罚 | 消耗 1 次机会，不损失鱼饵 `[提案]` |
