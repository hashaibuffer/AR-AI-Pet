# 产品与愿景

## 产品定义

**屿见 YUSEE 是连接智能眼镜与智能硬件的开放式个人 Agent 系统。**

它把智能眼镜的第一视角感知、个人 Agent 的理解与记忆，以及智能硬件的现实表达连接为统一体验：Agent 不只停留在聊天框中，而是能够理解用户所处的情境、规划任务、调用工具，并通过合适的终端给出反馈或采取行动。

| 组成 | 在系统中的角色 |
|---|---|
| 智能眼镜与多端入口 | 提供第一视角感知、自然交互和即时反馈 |
| YUSEE Agent | 理解用户、维护记忆、规划任务、调用工具和组织主动行为 |
| 智能硬件 | 成为 Agent 在现实世界中的表达、感知与行动载体 |
| 开放模块生态 | 让开发者和厂商持续扩展软件能力、体验与设备支持 |

屿见的定位不是某一款眼镜的应用，也不是某一台桌宠机器人的控制软件，而是面向智能眼镜与具身设备的 **Agent 大脑层和生态层**。

## 我们解决的问题

智能眼镜、个人 Agent 和智能硬件正在快速发展，但它们通常彼此割裂：眼镜能够显示和感知，却缺少持续理解用户的智能核心；Agent 擅长对话和处理数字任务，却很少进入现实环境；智能设备拥有动作和传感器，却难以共享用户上下文、人格与长期记忆。

屿见在三者之间建立统一的闭环：

```text
感知 → 理解 → 规划 → 调用工具 → 执行 → 反馈 → 形成记忆
```

这使 Agent 能够从“回答问题”升级为长期存在、可以完成任务并与现实世界协作的个人智能体。

## 为谁创造价值

### 用户

用户获得一个跨眼镜、App 与智能硬件持续存在的个人 Agent。它可以理解生活、工作和学习中的上下文，用合适的方式提醒、协助和陪伴，并在用户授权范围内保持连续的偏好、关系与记忆。

### 开发者与内容创作者

开发者可以围绕统一模块规范开发工具、人格、游戏、工作流和交互体验，无需重复搭建完整 Agent 系统。内容创作者也可以将角色设定、行为规则、内心 OS 和虚拟生活转化为可安装的体验模块。

### 眼镜与硬件厂商

厂商通过标准适配器接入设备能力，即可获得 Agent、记忆、工具和应用生态。设备更换或新增型号时，不需要重写上层用户数据和 Agent 逻辑。

## 核心产品能力

- **情境理解**：结合语音、视觉、通知、位置和设备状态理解用户所处场景。
- **任务规划**：把自然语言目标拆成可执行步骤，并在执行后检查结果。
- **工具调用**：按需调用日程、待办、天气、内容服务、智能家居与第三方应用。
- **长期记忆**：沉淀稳定偏好、重要经历和关系信息，支持持续个性化。
- **主动交互**：依据时间、情境、用户状态和事件规则发起合适的提醒或陪伴行为。
- **多端表达**：在眼镜、App、机器人和其他设备之间选择合适的信息与动作通道。
- **硬件行动**：通过适配器调用设备的显示、声音、灯光、姿态、移动和传感器能力。

## 应用方向

| 方向 | 典型体验 |
|---|---|
| 个人事务 | 创建日程、整理待办、消息摘要、主动提醒与状态记录 |
| 工作与学习 | 任务拆解、专注协助、休息提醒、知识引导和轻量信息提示 |
| 情感陪伴 | 人格化交流、情绪反馈、长期关系、欢迎与日常仪式 |
| 游戏与虚拟生活 | 农场经营、宠物生活、桌面游戏以及虚实联动事件 |
| 智能生活 | 智能家居、天气出行、做饭协助、家务提醒和健康习惯 |
| 第一视角协助 | 理解用户所见内容，将现场信息转化为行动建议或工具任务 |

## 首个参考应用

屿见 Companion 是框架的首个参考应用。它通过智能眼镜呈现 Agent 的数字世界，通过桌宠机器人提供实体陪伴，并由 App 承担配置、记录和扩展交互。

参考实现中的人格、提醒、虚拟生活、农场和游戏都以模块形式组织；智能眼镜和桌宠机器人只是当前参考终端，不构成平台的硬件限制。未来，同一套 Agent 与用户记忆可以迁移到不同品牌的眼镜、机器人、智能家居和具身设备。

## 长期愿景

屿见希望成为具身智能行业可复用的“大脑层”：让设备厂商专注硬件，让开发者专注能力与体验，让用户拥有不被单一终端绑定的个人 Agent。

长期方向包括：

- 兼容主流智能眼镜、桌宠机器人和更多具身设备；
- 建立统一的模块、权限、能力发现与硬件适配规范；
- 支持用户身份、人格和记忆在授权设备间持续迁移；
- 建立由开发者、内容创作者和硬件厂商共同参与的模块生态；
- 提供本地、家庭服务器和云端可组合的部署方式；
- 让个人 Agent 从信息助手进一步成为现实生活中的长期伙伴与行动中枢。

## 商业模式

屿见采用 **Open Core** 商业模式，以开放基础框架扩大设备兼容与开发者生态，以云服务、高级模块和企业能力实现可持续经营。

| 开源基础 | 商业服务 |
|---|---|
| Agent 基础框架与模块规范 | 托管 Agent 云服务与模型路由 |
| 基础通信协议和工具接口 | 云端记忆、跨设备同步与备份 |
| 智能眼镜参考客户端 | 高级人格、游戏、效率和行业模块 |
| 示例工具与硬件适配器 | 官方认证硬件适配包与技术支持 |
| 本地部署能力 | 企业私有部署、OEM 与预装授权 |

基础能力保持开放，开发者可以自由构建和组合模块；用户和企业则可以按需购买更强的云端能力、内容体验、设备支持和服务保障。

## 产品原则

- **Agent 优先**：功能围绕感知、决策、工具执行和结果交付形成闭环。
- **模块可插拔**：能力可以独立安装、升级、替换和移除。
- **硬件可替换**：设备差异收敛在适配层，不绑定单一品牌。
- **用户可控制**：感知、记忆、工具和硬件权限由用户授权和管理。
- **行动可解释**：Agent 能说明调用了什么能力、获得了什么结果。
- **本地与云协同**：根据隐私、成本、性能和设备条件选择部署方式。
