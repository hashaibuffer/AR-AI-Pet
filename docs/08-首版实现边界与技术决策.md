## 当前统一服务实施

为让 Beam Pro、设备和 Agent 在局域网内使用一个明确入口，首版增加可选 Compose profile `unified`：

```text
Beam Pro / Unity  →  /ws/app
StackChan         →  /ws/device
外部 MCP 客户端   →  /mcp
                       │
                 ar-aipet-server
                       │
            PostgreSQL / Memory / Adapter
```

这只是部署与连接收敛，不改变数据库、游戏规则或 Mem0 的数据职责。统一服务中的 Agent 默认使用内置语义工具注册表；FastMCP Hub、旧 Robot Bridge 和旧 WebSocket 地址暂时保留作兼容与回滚。设备会话同时接受 `device-v1` 与 Scheme B `hello`/`mcp` 协议，正式固件是否需要移植客户端仍以固件源码收敛和实体测试结果为准。

软件验收命令：

```powershell
cd services/agent-service
docker compose --profile unified up --build -d
docker compose --profile unified exec -T ar-aipet-server python scripts/unified_smoke.py
docker compose --profile unified exec -T ar-aipet-server python scripts/mcp_smoke.py
```

上述 smoke 只证明统一服务、Mock 设备、MCP 兼容入口和数据库闭环；不替代 Beam Pro、StackChan、NanoDrive 实体观察。

## 首版架构边界

- Unity App 是用户主入口，承载 Beam Pro 手机 UI、XREAL AR、游戏、日程和设备控制。
- 局域网电脑或家庭服务器运行 PostgreSQL 数据服务、AR-AIPet MCP Hub 和 Mem0 Worker。
- 项目自有本地 Agent Runtime 是当前文字主 Agent，负责文字会话、任务理解和工具调用。
- AR-AIPet MCP Hub 向本地 Agent Runtime 提供项目状态、日程、记忆和设备工具。
- Xiaozhi/StackChan 固件继续提供设备语音和实体能力；语音协议网关不在本轮。
- Mem0 保存长期语义记忆；不保存日程、游戏数值和设备状态。
- StackChan 固件提供 Xiaozhi 会话链路和 Kimito 行为 MCP；Kimito 不作为业务状态权威。
- NanoDrive 仅执行运动指令与本地停止。

## 数据原则

- 原始事件、日程、游戏和家园状态以 PostgreSQL/业务数据库为唯一事实来源。
- 偏好、习惯、关系和重要事实异步进入 Mem0。
- Mem0 写入失败不得阻塞原始数据入库或本地交互。
- 当前文字 Agent 通过 MCP Hub 访问项目数据；StackChan 语音链路尚未接入本地 Agent Runtime。
- 当前 `conversationId` 用于归档并读取最近短期上下文；Mem0 长期记忆通过独立 Memory Service 异步接入。

## 内容与体验基线

- 正式人格、主动触发、内心 OS、情绪动作映射和文案基线位于 [`content/design/`](../content/design/) 与 [`content/runtime/`](../content/runtime/)。
- GDD 是玩法规则事实来源；运行时 JSON 是代码读取的版本化快照。Agent 不能改骰子计分、农场成长或结算顺序。
- 《六面星河》首版为用户与宠物对战：五颗骰子、双方各 11 回合、每回合最多 3 次投掷；《一寸春》保留机器人自己的小田，用户工作时可自主照料。
- 口播与 XR/Beam Pro 内心 OS 分开生产；内心 OS 是短旁白，不是链式思考。文案缺失时回退固定模板，设备动作以 `ActionResult` 为准。
- 内容变更应同时更新编辑源、运行时 JSON 和对应验收说明；不把临时台词直接散落到 Agent 代码中。

## 本轮不做或不作为阻塞项

- QwenPaw 已废弃并仅作历史归档；AgentScope 和多 Agent 不属于当前技术路线。
- 真实模型、Mock、真实 Mem0、语音验证必须分开记录；当前先完成 Mock 记忆闭环，真实 Mem0 需凭据后单独验收。
- 多人联机、SLAM 等不属于本轮阻塞项。
- 自主巡航、远程机器人运行。
