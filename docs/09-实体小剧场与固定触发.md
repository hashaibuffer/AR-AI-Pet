# 实体小剧场与固定触发

首版只实现七个确定性场景：唤醒、晚安、玩乐、回家、提醒、安慰、跳舞。

## 调用规则

语音转成文字后，先由 `ExactSceneRouter` 做标准化和允许词包含匹配。命中固定场景时直接生成 `scene.play`，不调用大模型；其他自然语言继续走 Agent 推理。Beam Pro/Unity 使用 Agent WebSocket；StackChan 侧由主语音会话直接调用本地 `scene.play` 工具。独立动作网关不是语音入口，也不是当前演示前置条件。

唤醒由 StackChan 固件唤醒事件直接触发，不等待语音转写，也不能阻塞后续监听。

场景统一使用一个语义动作：

```text
scene.play(sceneId, durationMs, steps)
```

`steps` 只描述屏幕、灯光和头部的语义动作，不出现 PWM、电机寄存器或串口参数。当前固定剧本不包含底座移动；底座仅由实体遥控器控制。

## 固定词

| 场景 | 固定词 |
|---|---|
| 唤醒 | 固件唤醒词事件 |
| 晚安 | 晚安、我要睡了、睡觉了 |
| 玩乐 | 陪我玩、玩一下、玩起来、玩乐、和我玩 |
| 回家 | 我回来了、我到家了、回家了 |
| 提醒 | 提醒我、喝水提醒、休息提醒、提醒喝水、提醒休息、工作提醒、日程提醒 |
| 安慰 | 安慰我、我有点难过、陪陪我 |
| 跳舞 | 跳舞、跳个舞、给我跳舞、跳舞吧、跳一段 |

“我不想跳舞”一类带否定的语句不会触发固定场景，会交给 Agent 判断。

## 语音与动作

首版语音只安排在动作前或动作后，不要求语音和头部舵机同时运行。屏幕和灯光在同一时间点可以并行；场景开始时先播放 `voiceBefore`，再执行实体时间轴；`voiceAfter` 等动作完成事件接通后再启用。底座不由固定剧本驱动。

唤醒不额外插入 TTS，只保留现有唤醒提示音，以保证用户可以立即继续说话。

## 安全约束

- 当前固定剧本不得产生底座移动指令；底座只接受实体遥控器输入。
- 新唤醒、新命令和紧急停止可以打断当前场景。
- 场景结束必须恢复脑袋安全姿态并恢复待机灯光。

## 实现边界

- Agent 服务：固定词路由、场景前后语音、事件记录和自然语言回退。
- Robot Bridge：只传递 `scene.play` 语义动作，不解释硬件参数。
- StackChan 当前演示：官方 Xiaozhi 主语音直接调用 voice-emoji 固件内置 `self.scene.play` / `self.scene.stop` 及 Emoji、灯光、舵机工具；独立动作 MCP 与 Robot Bridge 作为后续扩展保留。
- Mock Robot：只验证场景接受、完成、取消和结果回传。

### 当前映射

| 语义步骤 | 固件动作 | 说明 |
|---|---|---|
| `display.emotion/icon` | `self.display.set_emotion` | `clock`→`thinking`，`music`→`laughing`，其余使用同名内置 Emoji |
| `led.effect` | `self.led.set_all` / `self.led.clear` | 渐变、呼吸和彩虹在 Bridge 侧展开 |
| `head.pose` | `self.robot.set_head_angles` | 只使用已验证的安全角度范围 |

七个剧本已搬入 voice-emoji 固件，并改为更密集的多节拍表现：Emoji、灯光和头部动作交替变化，时长约 4.8—12 秒。固定剧本由 StackChan 主语音调用 `self.scene.play`，由设备本地时间轴执行；底座不参与剧本。独立动作网关已完成一次历史单动作冒烟，但不属于当前演示主链路。

本首版不加入猜拳、干杯、小动物和鲜花素材；这些属于后续图标资源包，不影响七个场景的接口。
