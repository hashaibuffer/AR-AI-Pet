# 硬件与底座方案

## 已确认信息

- NanoDrive 使用 Arduino Nano，商家提供原理图，可使用 Arduino IDE 开发。
- 商家资料包含编码器读取和 PID 示例。
- 底座可通过串口接收运动指令，IO 已引出，可自行连接传感器。
- NanoDrive 套餐价格为 99 元。
- 配套 2S 380mAh 电池不带保护板。
- 最低工作电压和最终充电方案待负责人确认。

## 项目结论

NanoDrive 适合作为首版基础运动执行底座。它本身没有 Wi-Fi，需要由 StackChan 或其他通信模块转发串口指令。当前采用 StackChan → BK3432/JDY-23A 类 BLE 模块 → NanoDrive 的透明串口路径。

当前目标仅包括基础移动、停止、指令超时停止和断连保护；上述能力已完成实体验收。SLAM、自动巡航、自动回充等扩展能力不属于当前已实现范围。

## 到货后验证

B 收到实物后已完成以下优先验证：

1. 运动方向、停止、编码器与 PID 基准。
2. 指令超时、断连和重新上电默认停止。

实际最低工作电压与电池保护/充电方案不作为本轮软件闭环的验收项，后续按硬件使用规范单独确认。

实际结果记录到 [`docs/07-测试与Demo验收.md`](07-测试与Demo验收.md)。

## 降级方式

若底座不兼容或未在 Day 7 接入截止前到货，演示使用 `MockBaseAdapter` 或固定不移动的 StackChan。AR、AgentOS、游戏和 StackChan 表现继续联调，不因底座阻塞主体 Demo。
